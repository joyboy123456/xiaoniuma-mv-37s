# 句级时间轴（秒）

方法：faster-whisper small（带歌词提示 / 不带提示两版）给出逐字时间 → 用 300–3000 Hz 人声能量包络（work/audio/tempo2.py，50 ms 粒度）逐句核对起音点并修正。
**注意：本轮由 Hark 在云端完成，无法进行真人耳机听审；下列时间点是 ASR + 能量包络交叉校对的结果，建议委托人用耳机复核一遍。**
