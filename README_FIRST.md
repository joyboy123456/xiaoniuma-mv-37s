# 从这里开始

1. 把本压缩包交给 Claude，并粘贴 `PROMPT.md` 的全文。包内没有另一位创作者的成片、截图或源码，可直接开展独立创作。
2. `assets/song_37s.m4a` 是已确认的 37 秒歌；`lyrics.txt` 是已确认歌词。
3. `starter/` 是 John Heibel 的 ClaudeAnimationBase 的可运行源码和技术说明，保留原 MIT LICENSE。上游文档中的参考图片未打包，最新版本见 https://github.com/JohnHeibel/ClaudeAnimationBase 。
4. Claude 完成并导出自己的最终版后，再打开单独的对比包。
